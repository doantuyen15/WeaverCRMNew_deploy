3. Auto-rotate token (flow)

1. FE: GET /v25.0/feed?access_token=$VITE_FB_PAGE_TOKEN
2. FB: 400 OAuthException code=190 subcode=2069032 ("Session has expired")
3. FE: POST /us-central1/socialRotatePageToken   ← CF mới
4. CF : đọc META_USER_TOKEN từ Secret Manager
        + APP_ID/APP_SECRET từ env
        → /oauth/access_token?grant_type=fb_exchange_token
        → /me/accounts → trả về PAGE token mới
5. FE: lưu token vào localStorage + memory cache
6. FE: retry GET /feed với token mới  →  200 OK ✓

→ Toàn bộ silent. UI không hiện banner. Nếu rotate fail → banner đỏ "Không thể refresh token, paste token mới vào .env.local".
