# Agent report fonts

Chat reports and PDF exports share Noto Sans Regular/Bold and Noto Sans Mono Regular.
Fonts are bundled locally; PDF generation does not contact Google Fonts.

- `agent-noto-sans.ttf`: existing Noto Sans Regular; SIL Open Font License in `OFL.txt`.
- `agent-noto-sans-bold.ttf`: [Noto Sans Bold](https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Bold.ttf), SHA-256 `c976e4b1b99edc88775377fcc21692ca4bfa46b6d6ca6522bfda505b28ff9d6a`.
- `agent-noto-sans-mono.ttf`: [Noto Sans Mono Regular](https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSansMono/NotoSansMono-Regular.ttf), SHA-256 `d9e2b23d19f8230be7146f409a52b1d23117e635e28f2e2892cf91b7382f325b`.

The added fonts were downloaded from the Noto project's official repository on 2026-10-17; their license is bundled in `NotoFonts-OFL.txt`.
